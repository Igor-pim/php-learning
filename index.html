📖 Справочник

<h1>...</h1>
Самый большой заголовок. Бывают от <h1> (огромный) до <h6> (маленький)
Пример: <h1>Привет!</h1>
<p>...</p>
Обычный текст (параграф). Каждый <p> начинается с новой строки
Пример: <p>Это мой текст</p>
<div>...</div>
Контейнер — невидимая "коробка" для группировки элементов. Сам по себе ничего не показывает, но можно задать фон, рамку и т.д.
Пример: <div style="background: yellow;">Блок</div>
<span>...</span>
Как <div>, но для кусочка текста внутри строки. Не переносит на новую строку
Пример: Привет, <span style="color:red;">мир</span>!
<b>...</b>
Делает текст жирным
Пример: <b>Важно!</b>
<i>...</i>
Делает текст курсивом (наклонным)
Пример: <i>красиво</i>
<br>
Перенос строки. Не имеет закрывающего тега!
Пример: Строка 1<br>Строка 2
<a href="...">...</a>
Ссылка. href — адрес, куда ведёт
Пример: <a href="https://google.com">Google</a>
<img src="..." />
Картинка. src — адрес изображения
Пример: <img src="photo.jpg" />
<ul> и <li>
Список с точками. <ul> — сам список, <li> — каждый пункт
Пример: <ul><li>Пункт 1</li><li>Пункт 2</li></ul>
style="..."
Атрибут для добавления стилей прямо в тег. Внутри пишутся CSS-свойства
Пример: <p style="color: blue; font-size: 20px;">Синий текст</p>
color
Цвет текста. Можно писать по-английски или кодом
color: red; или color: #FF0000;
background
Цвет фона
background: yellow; или background: #FDCB6E;
font-size
Размер шрифта в пикселях. Обычный текст — 16px
font-size: 24px;
font-family
Шрифт текста
font-family: Arial; или font-family: "Comic Sans MS";
text-align
Выравнивание текста: по левому краю, по центру или по правому
text-align: center; или text-align: left;
padding
Отступ внутри элемента (между текстом и краем "коробки")
padding: 20px; — отступ 20 пикселей со всех сторон
margin
Отступ снаружи элемента (между "коробками")
margin: 10px; — отступ 10 пикселей вокруг
border
Рамка вокруг элемента
border: 2px solid red; — красная рамка толщиной 2 пикселя
border-radius
Скругление углов
border-radius: 16px; — круглые углы. border-radius: 50%; — круг!
Популярные цвета
red, blue, green, yellow, purple, pink, orange, white, black
Или используй коды: #FF6B6B, #4ECDC4, #45B7D1
echo "текст";
Вывести текст на страницу. Не забудь кавычки и точку с запятой!
echo "Привет!";
$переменная = значение;
Создать переменную. Имя всегда начинается с $
$name = "Вася"; или $age = 9;
. (точка)
Склеивает строки вместе
echo "Привет, " . $name . "!";
"текст $var"
В двойных кавычках переменные подставляются автоматически!
echo "Мне $age лет"; — выведет "Мне 9 лет"
if / elseif / else
Проверка условий. Если условие верно — выполняется код в { }
if ($x > 10) { echo "Много!"; } else { echo "Мало!"; }
for ($i = 0; $i < N; $i++)
Цикл — повторяет код N раз
for ($i = 1; $i <= 5; $i++) { echo "⭐"; }
$arr = [...];
Массив — список значений. Нумерация с нуля!
$arr = ["яблоко", "банан"]; → $arr[0] = "яблоко"
foreach ($arr as $item)
Пройти по каждому элементу массива
foreach ($fruits as $f) { echo $f; }
function имя($параметр)
Создать свою команду (функцию). return — вернуть результат
function add($a, $b) { return $a + $b; }
// комментарий
Текст после // — подсказка для тебя. Компьютер его игнорирует
